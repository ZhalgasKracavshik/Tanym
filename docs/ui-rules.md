# Правила интерфейса Tanym

Документ появился из конкретного диагноза. Замеры по коду показали:
все 15 страниц открывались одинаковым заголовком с подзаголовком, все 11 обёрток
имели одинаковые поля и отступ, единственной поверхностью в продукте была карточка,
интервал между всеми блоками был один и тот же `mt-6`, а в шапках карточек стояли
грозди из трёх и четырёх плашек.

Именно эта идеальная однородность и читается как «сделано нейросетью». Живой интерфейс
неровный: в нём есть плотные группы, крупные паузы и на каждом экране одна вещь,
которая заметно крупнее остальных.

---

## 1. Четыре поверхности вместо одной

Карточка перестаёт быть единственным способом положить что-то на экран.

| Поверхность | Как выглядит | Когда применять |
| --- | --- | --- |
| **Голая** | Контент прямо на фоне, разделён волосяными линиями `border-ink-200` | Строки метрик, панели фильтров, вводные абзацы разделов |
| **Строка с рейкой** | Ряд с цветной полосой слева шириной 3px, кодирующей состояние | Списки тем, заданий, объявлений, всё, что перечисляется |
| **Карточка** | `rounded-2xl border shadow-[var(--shadow-rest)]` | Только самодостаточные единицы: событие, объявление маркетплейса, рекомендованная тема |
| **Панель** | Рамка без тени, `rounded-xl border` | Таблицы и плотные данные |

Правило проверки: если элемент нельзя мысленно перенести на другой экран целиком,
он не карточка.

---

## 2. Четыре способа открыть страницу

Соседние по навигации страницы не должны открываться одинаково.

**А. Заголовок с подписью в строку.** Крупный `h1`, рядом на той же базовой линии мелкая
серая подпись. Первый экран сразу показывает данные, а не описание.
Применяется: кабинет, профиль.

```tsx
<div className="flex flex-wrap items-baseline gap-x-4 gap-y-1">
  <h1 className="text-3xl font-semibold text-ink-900 sm:text-4xl">Привет, Аружан</h1>
  <p className="text-sm text-ink-400">9 класс</p>
</div>
```

**Б. Микроподпись над крупным заголовком.** Строчка заглавными с разрядкой, под ней
заголовок. Даёт ощущение раздела, а не страницы.
Применяется: архив, возможности, афиша.

```tsx
<p className="text-[11px] font-bold uppercase tracking-[0.2em] text-brand-600">Материалы</p>
<h1 className="mt-2 text-3xl font-semibold text-ink-900 sm:text-4xl">Архив заданий</h1>
```

**В. Контекстная строка над заголовком.** Плашки предмета и сложности, под ними название.
Применяется: изучение темы, материал архива.

**Г. Заголовок без подписи, сразу цифры.** Ниже идёт полоса показателей.
Применяется: объявления, рейтинг, панель учителя.

---

## 3. Ступени вертикального ритма

Одинаковый отступ между всем убивает группировку. Четыре ступени, других нет:

| Ступень | Значение | Между чем |
| --- | --- | --- |
| Внутри группы | `mt-2` | Заголовок и его подпись, число и его пояснение |
| Между родственными блоками | `mt-4` | Карточки в одном списке |
| Между разделами | `mt-10` | Список тем и блок слабых мест |
| Перед новой областью | `mt-16` | Основной контент и вспомогательный раздел внизу |

---

## 4. Шкала кегля и контраст

| Роль | Размер | Начертание |
| --- | --- | --- |
| Главное число экрана | `text-4xl` или `text-5xl` | `font-semibold` |
| Заголовок страницы | `text-3xl sm:text-4xl` | `font-semibold` |
| Заголовок раздела | `text-lg` | `font-bold` |
| Основной текст | `text-base` | обычное |
| Подпись | `text-xs uppercase tracking-wide` | `font-medium` |

Правило контраста: **самый крупный элемент экрана должен быть минимум втрое больше
подписи рядом с ним.** Если всё лежит в диапазоне от 14 до 24 пикселей, экран выглядит
плоским независимо от цветов.

Заголовки набираются плотнее текста (это уже в `globals.css`), цифры всегда
`tabular-nums`.

---

## 5. Один главный элемент на экран

На каждом экране ровно одна вещь, за которую цепляется глаз при первом взгляде.

| Экран | Главный элемент |
| --- | --- |
| Кабинет | Точность крупной цифрой в строке показателей |
| План | Объяснение наставника, отделённое от списка тем |
| Изучение темы | Условие задания, набранное крупнее всего на экране |
| Диагностика, итог | Процент в размере `text-6xl` |
| Достижения | Серия дней с иконкой пламени |
| Архив | Пояснение метода Сократа |
| Афиша | Обратный отсчёт у ближайшего дедлайна |
| Рейтинг | Строка самого ученика, выделенная фоном |
| Панель учителя | Число учеников в зоне риска |

---

## 6. Плашки

Не больше двух в шапке блока. Третья и последующие уходят в строку подробностей
ниже обычным текстом. Грозди плашек это первый признак сгенерированной вёрстки.

---

## 7. Что остаётся неизменным

Эти вещи менять нельзя, они уже проверены:

- Иконки только из набора `src/components/Icon.tsx`, никаких эмодзи
- Ни одного длинного тире в строках интерфейса
- Область нажатия не меньше 44 пикселей у основных действий
- Видимый фокус с клавиатуры на всех интерактивных элементах
- Цвет никогда не единственный носитель смысла, рядом всегда текст или иконка
- Все подписи в трёх языках с одинаковым набором ключей
