taným - персональная AI-платформа и образовательная экосистема для школьников Казахстана, 
сокращающая разрыв в качестве образования между городами и регионами.
Качественное образование в Казахстане распределено неравномерно. Ученик в областном центре
может нанять репетитора, а ученик в ауле не может. Учитель физически не успевает найти пробел
у каждого из тридцати человек в классе. Taným решает это тем, что даёт каждому ученику
персональную траекторию, а учителю карту пробелов всего класса.


**Что умеет MVP**
**Обязательное требование кейса | Где реализовано**
Главная страница с ценностным предложением | "/" 
Профиль ученика: класс, предмет, цель |  "/profile"
Диагностика уровня знаний | "/diagnostics/[subjectId]" 
AI-модуль персонализации | "/plan" + "src/lib/personalization.ts"
Минимум 2–3 темы с заданиями | 3 предмета × 4 темы = 12 тем, 96 заданий 
Личный кабинет с прогрессом и слабыми местами | "/dashboard" |
Панель учителя с добавлением тем | "/teacher"
Обратная связь по заданиям | "/learn/[topicId]" + "/api/ai/feedback"
Дополнительно: AI-чат наставника, геймификация (очки за сложность заданий),
адаптивная сложность, мобильная вёрстка, мультиязычный интерфейс, напоминания о дедлайнах.


## Как работает искусственный интеллект
ИИ разделен на 2 слоя

### Слой 1. Движок персонализации на "src/lib/personalization.ts"

работает без интернета. он решает что рекомендовать.

1. **Модель ученика по навыкам** Уровень считается не по темам, а по атомарным навыкам
  (теорема Виета,закон Ома). Оценка обновляется экспоненциальным скользящим средним,
  где вклад попытки зависит от сложности задания: верный ответ на сложное — сильное
  доказательство знания, ошибка в олимпиадной задаче почти не роняет оценку.
2. **Ранжирование тем** Приоритет = 0.45 × пробел + 0.2 × готовность (пройдены ли
  темы-предпосылки) + 0.2 × соответствие цели + 0.15 × незавершённость. Веса собраны
  в одном месте и подписаны.
3. **Адаптивная сложность.** Скользящее окно из 4 последних попыток, >=75% верных - уровень
  вверх, <=25% - вниз.

### Слой 2. Языковая модель - Google Gemini

Отвечает за "почему" и "как обьяснить". Модель получает готовые цифры из движка и эталонное решение из контента,
и переводит это в человеческую речь. Поэтому объяснение никогда не расходится с тем,
что ученик видит на экране.
Три сценария:

| Эндпоинт | Что делает |
| --- | --- |
| POST /api/ai/feedback | Разбирает ответ на задание. называет ошибку, объясняет верный ход |
| POST /api/ai/plan | Объясняет персональный план, что показала диагностика и с чего начать |
| POST /api/ai/chat | Отвечает на вопросы ученика по теме, не выдавая готовых решений ДЗ |

**Надёжность.** У каждого сценария есть детерминированный дублёр (src/lib/ai/fallback.ts).
Если API недоступен, перегружен или закончилась квота ученик всё равно получает разбор. Интерфейс помечает это меткой "Разбор без AI"
вместо Ответа от AI.
Дополнительно работает цепочка запасных моделей. При проверке gemini 3.7 flash вернула 503,
и запрос автоматически ушёл на gemini 3.5 flash.

**Безопасность ключа.** Ключ живёт только в переменной окружения на сервере. Страницы
обращаются к собственным роутам /api/ai/*, и оттуда уже идёт запрос в Google. Если бы
модель вызывалась прямо из компонента, ключ попал бы в браузерный бандл.


**Технологический стек**

**| Слой | Технология | Почему так |**

| Фронтенд | Next.js 16 (App Router), React 19, TypeScript strict | Один проект на страницы и API, строгая типизация контента |
| Стили | Tailwind CSS v4 | Дизайн-токены в "globals.css", без разъезжающихся стилей |
| ИИ | Google Gemini API (REST, без SDK) | Бесплатная квота, виден точный HTTP-запрос |
| Данные ученика | localStorage | потомучто кейс допускает mock-хранилище; а так, структура готова к переносу в БД |
| Учебный контент | Типизированные TS-модули | Контент проверяется компилятором и версионируется вместе с кодом |
| Хостинг | Vercel | Нулевая настройка для Next.js |

Ученик отвечает
    POST /api/ai/feedback { taskId, answer, ... }
    сервер находит задание в реестре и САМ проверяет ответ
     (клиенту нельзя доверять оценку правильности)
    промпт с эталонным решением → Gemini
    ответ + метка live/fallback
    recordAttempt() обновляет навык, прогресс темы, очки и уровень сложности
    изменения сразу видны в /dashboard, /plan и в панели учителя


**Запуск**

Нужен Node.js 20 или новее.

```bash
git clone <адрес репозитория>
cd Tanym
npm install
```
Получите бесплатный ключ в [Google AI Studio](https://aistudio.google.com/apikey),
скопируйте .env.example в .env.local и вставьте его.
```bash
cp .env.example .env.local
```
Проверьте, что ключ работает
```bash
node scripts/check-ai.mjs
```
Запустите:
```bash
npm run dev
```
Откройте http://localhost:3000
Без ключа приложение тоже работает. Все экраны, движок персонализации, диагностика
и задания функционируют, а вместо ответов модели показываются готовые разборы с пометкой
Разбор без AI.
